## Content Hosting and Streaming Architecture

RRadio is an interface and audio playback engine. It operates with strict separation of code and external media:

1. **No Proprietary Game Files**: This repository contains no extracted game binaries, scripts, or reverse-engineered game engine code.
2. **No Bundled Audio**: This repository and all compiled executable binaries do not host, store, package, or distribute copyrighted music or audio tracks.
3. **External Stream Endpoints**: Radio playback retrieves audio on the fly from publicly accessible web preservation archives (Archive.org).
4. **On-Demand API Integration**: On-Demand playback connects directly to YouTube Music using standard user authentication (OAuth 2.0 PKCE) or public YouTube embeds. RRadio does not download, rip, or bypass access restrictions.
