Windows Overlay Application

RRadio

RRadio is an open-source Windows desktop application that renders a transparent, non-intrusive radio HUD over your PC games. It emulates 8 authentic GTA Vice City style radio stations with 139 streaming tracks and integrates Discord Rich Presence.
